# arec

macOS 命令行录音工具：同时录制麦克风和系统声音，输出一个双声道 M4A 文件，适合交给支持多声道识别的 ASR 模型转写线上会议。

- 规格：AAC-LC · 24 kHz · 双声道 · 64 kbps
- 左声道是麦克风（我），右声道是系统声音（会议里的其他人）
- 需要 macOS 14.2+

## 安装

```bash
make install      # 安装到 ~/.local/bin/arec；make help 查看全部目标
```

## 使用

```bash
arec              # 开始录制，Ctrl+C 结束并保存
```

录制结束后得到：

| 文件 | 说明 |
|---|---|
| `<开始>_<结束>.m4a` | 完整录音 |
| `<开始>_<结束>_c.m4a` | 仅当录音里有 ≥ 5s 的静音时生成，长静音缩短为 1s |

环境变量：

| 变量 | 说明 |
|---|---|
| `AREC_OUTPUT_DIR` | 输出目录，默认为当前目录；不可写时警告并回退到当前目录 |
| `NO_COLOR` | 关闭彩色输出 |
| `AREC_DEBUG` | 打印诊断信息 |

## 特性

- **防丢失**：录制中实时写入 `<开始>_recording.aac`，进程崩溃或被 kill 也不会丢数据，下次运行时自动转成 `.m4a`。
- **跟随设备**：始终使用系统默认的输入和输出设备，切换设备时自动重连，录音不中断。
- **自动增益**：每个声道单独调整音量，并防止削波。
- **电源**：录制期间阻止空闲睡眠；合盖或系统睡眠时自动停止并保存。

## 权限

首次运行时，需要给运行 arec 的**终端 App** 开两项权限：

- 系统设置 › 隐私与安全性 › **麦克风**
- 系统设置 › 隐私与安全性 › 屏幕与系统录音 › **仅系统录音**

未授权时录到的是纯静音，界面会给出提示。

## 已知限制

- 权限授予的是终端 App；换一个终端运行需要重新授权。
- 切换设备的瞬间会有约 0.3s 的静音。
- 环境嘈杂时（周围一直有人说话），可能检测不到静音，也就不会生成 `_c` 文件。
- 使用蓝牙耳机的麦克风时，系统会切到通话模式，音质下降。
